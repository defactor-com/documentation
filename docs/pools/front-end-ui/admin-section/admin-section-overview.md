The **Admin Section** provides administrators with the tools to configure, secure, and manage pools on the Defactor platform. It centralizes all administrative tasks, making it easy to control account permissions, manage pool configurations, and perform protocol-level actions.  

---

## Structure  

The Admin Section is divided into two main areas:  

- **[Admin Accounts Settings](./admin-accounts.md)** – Manage who has administrative access. Add new accounts, edit account details, or revoke access.  
- **[Manage Pools Settings](./manage-pools.md)** – Oversee and configure pools. Edit pool details, set metadata, clone or create new pools, withdraw protocol fees, or pause contracts if required.  

## Key Features  

Across the Admin Section, administrators can:  

- **Control Access** – Assign, edit, or revoke admin rights to ensure only approved accounts can make changes.  
- **Configure Pools** – Set or update pool parameters such as APR, LTV ratios, and token oracles.  
- **Manage Metadata** – Define pool names, logos, descriptions, and terms to present pools transparently to users.  
- **Create & Clone Pools** – Deploy new pools or copy existing configurations for faster setup.  
- **Handle Protocol Fees** – Withdraw accumulated protocol-level fees to designated addresses.  
- **Emergency Controls** – Pause or resume contracts to protect users during audits, incidents, or maintenance.  

## Workflow Benefits  

- **Centralized Administration** – All critical admin actions in one place.  
- **Enhanced Security** – Access control and revocation prevent unauthorized changes.  
- **Operational Flexibility** – Pools can be updated, cloned, or paused to adapt to evolving requirements.  
- **Transparency** – Admin metadata ensures users have visibility into pool identity, parameters, and conditions.  

> The Admin Section is essential for maintaining **security**, **operational flexibility**, and **trust** across the Defactor Pools ecosystem.
