The **Engage Frontend** provides a unified interface for users to interact with the Engage ecosystem.  
From this dashboard, participants can stake tokens, track ecosystem metrics, participate in governance, view buyback activity, and monitor vesting schedules.  

This ensures transparency, accessibility, and engagement for all token holders across multiple blockchain networks.  

## Frontend Modules  

The frontend is organized into several main modules, each focusing on a key area of user interaction:  

- **[Ecosystem](/docs/engage/front-end-ui/engage-frontend-ecosystem#)** – Monitor circulating supply, staked value, buyback activity, liquidity, and wallet allocations across the ecosystem.  
- **[Staking](/docs/engage/front-end-ui/engage-frontend-staking#)** – Lock tokens into pools, earn rewards, view active/completed positions, and claim or restake tokens.  
- **[Governance](/docs/engage/front-end-ui/engage-frontend-governance#)** – Participate in decentralized decision-making by voting on proposals and tracking governance activity.  
- **[BuyBack](/docs/engage/front-end-ui/engage-frontend-buyback#)** – View ecosystem-wide buyback metrics, monitor buyback history, and initiate new buyback transactions.  
- **[Vesting](/docs/engage/front-end-ui/engage-frontend-vesting#)** – Track token vesting schedules, emissions charts, and claim vested tokens as they unlock.  

## Key Features  

- **Multi-Chain Support** – Switch between supported networks (Ethereum, Base, Polygon, etc.) seamlessly.  
- **Real-Time Data** – All dashboards update live with blockchain transactions and ecosystem events.  
- **Wallet Integration** – Connect your Web3 wallet to unlock personalized views (e.g., My Stats, My Buybacks, My Vesting).  
- **Transparency** – Every module provides full visibility into the Engage token economy, ensuring accountability for both users and administrators.  

> The Engage Frontend gives users the tools to actively participate in the ecosystem, while keeping all token activities visible and verifiable on-chain.
