The My Wallet section provides a comprehensive overview of all tokenized assets held in your connected wallet. This interface displays your complete portfolio of real-world asset (RWA) tokens, organized by asset category and providing detailed information about each holding.

---

## Wallet Overview

### Portfolio Display

The wallet interface presents your tokenized assets in a clean, organized table format, showing all essential information needed to track and manage your RWA token holdings.

**Table Structure**
The wallet displays six key columns providing comprehensive asset information:
- **Asset** - Asset category and classification
- **Name** - Specific asset or token identifier
- **Chain** - Blockchain network where the token exists
- **Amount** - Quantity of tokens held
- **Total Price** - Current USD valuation of holdings
- **Actions** - Management options (three-dot menu)

### Asset Management Actions

Each asset row includes an actions menu (three-dot icon) providing management options:

**Available Actions:**
- **Make a Pool** - Create a liquidity pool for the selected asset
- **Transfer Tokens** - Send tokens to another wallet address
- **Edit Information** - Modify asset metadata and details
- **Update Dynamic Data** - Refresh real-time asset valuations and metrics
- **Burn Assets** - Permanently remove tokens from circulation

*Note: Available actions may vary depending on asset type and user permissions.*
