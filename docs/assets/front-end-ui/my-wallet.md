This guide provides a comprehensive overview of the My Wallet interface, focusing on managing and viewing your tokenized asset holdings and portfolio balance.

---

## My Wallet Overview

![Assets My Wallet](../../../../documentation/static/img/front-end/assets/assets-my-wallet.png)

The **My Wallet** section serves as your personal portfolio management center, displaying all tokenized assets you currently hold across different blockchain networks. This interface provides detailed information about your asset holdings, their current values, and enables you to perform various wallet operations.

## Wallet Holdings Table

The main wallet interface displays your asset holdings in a comprehensive table format with the following information:

**Asset**
Displays the asset category or type with an associated icon for visual identification.

**Name**
Shows the full name or description of the specific tokenized asset you hold.

**Chain**
Indicates the blockchain network where the asset is deployed (e.g., ERC-3643, ERC-20).

**Amount**
Your current token holdings for this asset, showing both the quantity and token symbol.

**Total Price**
The current market value of your holdings in USD, calculated based on current token prices.

**Actions**
Three-dot menu (⋯) providing access to wallet management functions for each asset.

![Assets My Wallet Table Actions](../../../../documentation/static/img/front-end/assets/assets-my-wallet-table-actions.png)

**Make a Pool**
Create a liquidity pool for your held tokens to enable trading and provide liquidity to other users.

**Transfer Tokens**
Send tokens from your wallet to other addresses or users on the same blockchain network.

**Update Dynamic Data**
Refresh or modify dynamic data fields for assets you have management rights over.

**Burn Assets**
Permanently remove tokens from circulation, reducing both your holdings and the total token supply.
